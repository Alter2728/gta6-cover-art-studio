Sunset Cover Studio — a canvas cover maker for GTA 6-style multi-panel posters: 4 layouts (3-panel strip, full-bleed, 2-panel split, 2×2 grid), 4 in-canvas colour grades (Vice Sunset, Neon Nights, Palm Noir, Pastel Dawn), upload up to 3 photos, per-panel drag-pan / wheel-zoom / arrow-nudge, a caption editor, and one-click PNG export at 1080×1080, 1080×1350 and 1920×1080. Fully offline — no network requests. All artwork is original; no Rockstar logo, art, or fonts are used.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
